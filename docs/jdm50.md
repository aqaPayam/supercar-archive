# JDM batch: 50 new variants

Reviewed on 2026-10-27 against the 295-car catalogue at commit `73f7f8b`. The resulting catalogue contains 345 cars.

## Scope and evidence

- JDM means a Japan domestic-market specification. The Japan-spec EP3 and FN2 Civic Type R were assembled in Britain; their assembly country is recorded separately.
- Each entry represents the stated reference year and variant. Displayed year endpoints identify the research snapshot, not a claim that the entire generation was produced in one year.
- All technical details and stories link to manufacturer evidence. All 50 entries have one licensed representative exterior photograph with creator, license, original file page and file checksum. Photos can show another year, market or equipment specification; captions say so explicitly.
- Unknown prices, production totals, geography, acceleration and top speeds remain unfilled. Factory color availability is separate from verified production counts.
- Early Toyota gross power ratings are labeled; PS conversions use 1 PS = 0.73549875 kW. Anomalous Trueno curb-mass figures and conflicting ER34 torque figures are withheld rather than silently corrected.
- RX-8 Spirit R production announcements cover both transmissions; the manual-only total is not asserted. The Subaru 22B allocation is Japan-only.

## Repeatable import and validation

The reviewed data is in `data/jdm50.json`; the SQLite database already includes it. The importer uses only Python’s standard library. Preview or re-run safely:

```powershell
python scripts/import_jdm50.py
python scripts/import_jdm50.py --apply
python -m unittest test_startup test_jdm_import -v
python export_public.py
```

The importer rejects identity/ID collisions, checks source references and image checksums, validates the public payload, and commits all 50 profiles in one transaction. A manifest fingerprint prevents re-importing the same batch. Tests cover preservation of existing rows, exactly 50 additions, repeated import, collision rejection and full rollback on export-validation failure.

Batch content: 612 specification/identity details, 50 stories, 105 linked source records, 50 licensed photographs, 6 JPY price observations and 9 factory color records.
